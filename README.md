# oracle_shell_monitor

A small toolkit of shell + SQL\*Plus scripts for monitoring an Oracle
Database instance from the command line.

## Layout

```
oracle_shell_monitor/
├── README.md
└── monitor/             <- interactive monitor menu and SQL scripts
```

The main thing here is `monitor/`. See [`monitor/README.md`](monitor/README.md)
for full documentation, the menu reference, and quick-start instructions.

## Quick start

```sh
export ORACLE_HOME=/oracle/db/19c
export ORACLE_SID=PROD                  # adjust to your instance
cd oracle_shell_monitor
sh setup_executable_permissions.sh
monitor/monitor                         # main menu
```

Override the SYSDBA login if needed:

```sh
DB_USER=dba_user DB_PASS=mypass monitor/monitor
DB_USER=sys DB_PASS=manager DB_ROLE=sysdba monitor/monitor
```

## Executable Permissions

Executable bits are applied separately after checkout. From the
`oracle_shell_monitor` root, run:

```sh
sh setup_executable_permissions.sh
```

The script grants execute permission to the monitor entry points and helper
shell scripts under `monitor/`.

## Generated Files

The monitor creates a few runtime files under `monitor/`; they are ignored by
Git and should not be edited as source:

- `monitor/log/` - saved reports from menu `S`
- `monitor/sql/0_save_file.sql` - generated by `monitor/sql/0_save_file.sh`
- `monitor/sql/4_session_event.sql` - generated by menu `45`
- `monitor/sql/sqlid_format.sql` - generated by `monitor/monitor` and `monitor/auto_refresh.sh`

## Requirements

- Oracle Database 19c (CDB or non-CDB)
- `sqlplus` on `$PATH`
- DBA catalog access for dynamic performance views (`system/manager` by default)
- POSIX shell (`/bin/sh`); developed on Linux x86_64
- Diagnostic Pack license **only** if you use the AWR menu items (9*)
